This crate is a fork of [`servo/webrender`] published for use in [`zng-ui/zng`].

Feel free to use it in your own project, the API is the same, the crate is just renamed with `"zng-"` prefix and may contain
early patches that affect the ZNG project.

**Note** Since zng-0.22 we depend on the updated original crates when possible and this fork only releases early patch updates for bugs that affect Zng.
